# For every AI agent working in this repository

`CLAUDE.md` is the rulebook for **all** agents, not only Claude. Read it first, then `docs/HANDOFF.md` (start at section 0)
and `docs/TASKS.md`. They say which files your lane owns, how to claim a task, and the contest rules that disqualify the
project if broken (English only, every fact sourced, no NASA logo, no copyrighted text or music, no secrets).

Before every push: `npm run check` must be green, then `git pull --rebase`. Stage only the files of your lane.
